Core Features

Authentication & OAuth2

JWT access + refresh rotation, OAuth2 Swagger Authorize via /auth/token, password reset flow.

Transactions & Receipts

Expense/income/transfer CRUD, filtering, pagination, async receipt processing.

Budgets & Alerts

Category budgets with threshold alerts via hourly Celery Beat evaluation.

Reports & Exports

Async CSV and monthly reports with task polling endpoints.

Audit Trail

Append-only audit logs with admin query API for compliance forensics.
